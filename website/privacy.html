Privacy policy

Your audio stays on your Mac.

Semper is a local-first, open-source macOS app. It does not require an account, and the project does not receive the audio Semper processes.

Effective July 31, 2026

Updated July 31, 2026

Privacy Terms of use
00

The short version

  • No Semper account.
  • No sale of personal information.
  • No Semper-controlled analytics or advertising.
  • Audio is processed locally, not uploaded.
  • Settings and AutoEQ data stay on your Mac.
  • Random test assignments stay on your Mac or in your browser.
01

Scope

This policy applies to the Semper macOS app, the website at semper.systems, and information you send directly to Semper maintainers.

It does not govern GitHub, Vercel, Apple, the AutoEq project, or other third-party services. Their policies apply when you use them.

02

What Semper handles locally

Audio content

Semper uses Core Audio process taps to process app audio in memory for volume, routing, EQ, loudness, and limiting. It does not intentionally save that audio to disk or transmit it to Semper maintainers.

Apps and devices

Semper handles running-app information such as process identifiers, app names, bundle identifiers, icons, audio activity, and assigned settings. It also handles audio and Bluetooth device names, identifiers, capabilities, connection state, volume, mute state, and routing choices.

Preferences and diagnostics

Per-app audio settings, device preferences, AutoEQ selections, imported EQ profiles, display choices, and shortcuts are stored locally. Semper also writes operational messages and errors to the macOS unified logging system. Those logs remain under macOS control unless you choose to share them.

Experiment assignments

The app stores a random identifier and assigned interface variants in local preferences. The website stores a separate random identifier and page variants in local browser storage. Semper does not receive these values.

Main settings and the AutoEQ cache are stored under ~/Library/Application Support/Semper. macOS and included frameworks may also keep shortcut and update preferences in the app's preferences domain.

03

macOS permissions

  • Screen & System Audio Recording: required for the Core Audio process taps used for per-app audio control.
  • Microphone: used when Semper works with input-capable audio devices and input monitoring. Semper does not intentionally save or transmit microphone audio.
  • Bluetooth: used to list and connect paired Bluetooth audio devices.
  • Accessibility: optional, and used to intercept the system media keys for Semper's volume controls.

You can review or revoke these permissions in macOS System Settings under Privacy & Security. A feature will stop working if you revoke a permission it needs.

04

Network requests and third parties

AutoEQ

When you use AutoEQ features, Semper may download the AutoEq catalog and selected headphone profiles from raw.githubusercontent.com. Semper caches this data locally. GitHub receives normal request information such as IP address, request time, and client information.

Software updates

Semper includes the Sparkle update framework. It starts only when a release has a feed URL and public signing key. If you request or allow an update check, Sparkle contacts that feed and may download release information or an update. Any optional system-profile sharing presented by Sparkle is controlled by the choice shown to you.

Website hosting

Vercel hosts the Semper website and may process request information such as IP address, approximate location derived from IP, browser or system configuration, requested URL, timestamps, and security or performance data. Read the Vercel Privacy Notice.

GitHub

GitHub hosts the source repository, releases, issues, pull requests, and AutoEQ files. Repository contributions and public issues can include your profile, commit authorship, messages, and other information you publish. Read the GitHub General Privacy Statement.

05

Cookies and analytics

The Semper website does not add analytics scripts, advertising trackers, account cookies, or marketing cookies. Its experiment code stores a random identifier and assigned page variants in local browser storage so the same browser keeps seeing the same version. Experiment events remain inside the current page and are not sent to Semper or an analytics provider. Vercel may still use data needed to deliver, protect, and operate the hosted site as described in its privacy notice.

06

Information you send

If you contact a maintainer, open an issue, submit a pull request, or send a security report, the project may receive what you provide, such as your name, GitHub profile, contact details, message, code, logs, or device details. Maintainers use it to respond, review contributions, address bugs or security concerns, and administer the project.

Do not include private audio, credentials, or other sensitive information in a public issue. Use the private reporting instructions in SECURITY.md for security matters.

07

Retention and your choices

  • Local settings remain until you reset, replace, or remove the app's data.
  • Local app experiment assignments remain until you remove Semper's preferences.
  • Website experiment assignments remain until you clear site data for semper.systems.
  • AutoEQ downloads and imported profiles remain in the Semper Application Support folder until you remove them.
  • To remove local data, quit Semper and delete ~/Library/Application Support/Semper. You can remove Semper preferences through macOS and revoke permissions separately in Privacy & Security.
  • GitHub controls retention for public repository activity. Vercel controls retention for website request data.
  • Information sent privately to maintainers is kept only as long as reasonably needed to respond, maintain project records, handle security concerns, or meet legal obligations.

Semper maintainers do not sell personal information or use it for targeted advertising.

08

Security and children

Semper is built in public so its behavior can be inspected, but no software or storage method is completely secure. Keep macOS current, install Semper only from a source you trust, review permissions, and do not post sensitive information in public project spaces.

Semper is a general-purpose developer project and is not directed to children. The project does not knowingly collect personal information from children.

09

Changes and contact

This policy may change when Semper's features, hosting, or data practices change. The date at the top will be updated, and material changes will be noted in the repository.

For privacy questions or requests, contact the lead maintainer through a private contact method listed on Nihar Manchikakapudi's GitHub profile. Do not put sensitive personal information in a public issue.

The policy is versioned with the code. Read or propose changes on GitHub.
