Canary testing

Try the next build before release.

Canary builds are signed, notarized prereleases from the latest tested code. They may still regress audio routing, device handling, or the menu-bar interface.

Browse Canary builds Report a regression ↗
  1. 01

    Install the prerelease

    Download the newest Canary DMG from GitHub Releases.

  2. 02

    Confirm the channel

    Open Settings, then Updates. Select Canary if needed.

  3. 03

    Leave at any time

    Select Stable and check again after the next stable release.

Canary is for testing, not daily-critical audio. Include the Semper version, macOS version, and audio device when reporting a problem.

Built in the open.

Open source. Join the work.

Semper is a SwiftUI macOS project built on Core Audio process taps. Read the code, report an issue, or contribute a focused fix. The source, tests, guides, and issue tracker are open under GPLv3.
