# Semper support

Semper does not have a packaged public release yet. Support currently covers
building and testing the source on macOS 15.4 or later.

## Ask a question

Use [GitHub Discussions Q&A](https://github.com/niharnm/Semper/discussions/categories/q-a)
for build setup, permissions, routing configuration, AutoEQ, media keys, or
hardware behavior that is not yet a reproducible defect.

Before posting, check the [troubleshooting guide](guide/troubleshooting.md) and
search existing discussions.

## Report a bug

Use the repository's bug form when you can provide repeatable steps, expected
behavior, actual behavior, and a privacy-safe hardware description. Issues are
for work that can be reproduced or scoped, not general setup questions.

Do not attach captured audio or logs containing usernames, private paths,
personal device names, or unrelated process information.

## Request a feature

Use [GitHub Discussions Ideas](https://github.com/niharnm/Semper/discussions/categories/ideas)
for early proposals and tradeoff questions. Use the feature-request form when
the user problem, intended behavior, boundaries, and affected device classes
are clear enough to evaluate.

## Report a security problem

Use [private vulnerability reporting](https://github.com/niharnm/Semper/security/advisories/new).
Do not open a public issue or discussion for an undisclosed vulnerability.
